# Brief replay score: what a packet would have covered

Generated by `scripts/brief_replay_score.py`. Aggregates only; no paths, prompts,
commands or transcript text. Dollars are API list-price equivalents, not a bill.

## Sample

- Agent calls seen: 455; joined children scored: 424
- Unjoinable: 4 with no agentId in the tool result, 27 with a missing child transcript, 0 empty; 0 failed to render
- Child transcripts no parent call points at (excluded): 9; duplicate session copies skipped: 21
- Children that read at least one file: 342 of 424; with a redundant read: 176; priced: 422

## Method

- Join: parent `Agent` tool_use, then `toolUseResult.agentId`, then the child transcript.
- Facts at spawn: the parent's Read/Edit/Write paths, redacted Bash commands and todos from lines before the `Agent` call, rebuilt with `cfxd.session_state` shapes.
- Packet: `cfxd.brief_select.select` on those facts with the spawn prompt and the child's real model, rendered by `cfxd.brief_render`. Intent sections are omitted (they need parent message text), so packet bytes are a floor.
- Redundant read: a child `Read`/`NotebookRead`/`Grep` on a path the parent had already read or edited before the spawn (Gate 1's definition).
- Coverage: covered redundant reads / all redundant reads, pooled. Precision: packet files the child read / all packet files, pooled.
- Avoidable lower/upper: Gate 1's attribution (turn cost pro-rated by the turn's covered-read share; upper also charges the covered results carried to later turns) restricted to covered reads. `covered result tokens` is their chars/4 estimate.

## Caveats and bias

- One person's sessions on one machine. Many delegations are exploration tasks where the parent has read nothing, so the packet has nothing to offer by construction.
- Parent knowledge is only what its Read/Edit/Write/Bash calls show. Context from the user's prompt, compacted history or MCP tools is invisible.
- Path match is exact after slash/case normalisation; a file under another spelling is not matched.
- Packet bytes exclude intent sections and are measured on today's files: an excerpt can be truncated or degraded if the file changed or vanished, so real packets may differ slightly.
- Coverage says a path was in the packet, not that the child would have used it, and some re-reads are needed anyway to edit exact bytes.
