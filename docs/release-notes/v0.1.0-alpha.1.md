# Context Fabric v0.1.0-alpha.1

First alpha of the Claude Code plugin. **Experimental. The token saving is not proven.**

## What is in it
- Claude Code plugin (Windows, macOS, Linux): local daemon on 127.0.0.1 with brief (facts for sub-agents) and carry
  (working set across `/compact`); fold exists but is off by default.
- Offline, counts-only analysis of your own transcripts: `cfxd audit`, `diet`, `waste`, `replay`.
- Hooks are authenticated with a per-install token and fail open.

## What we measured (exploratory, one developer's machine)
- Folding file reads cost +101% tokens on read-everything tasks, so it is off.
- Shrinking old tool results saves at most about 7% (optimistic bound).
- About 14K of a 62K first-turn context comes from the user's own setup.

## Install
See [docs/INSTALL-ALPHA.md](../INSTALL-ALPHA.md). Pin this version:
`claude plugin marketplace add Pranavk098/context-fabric#v0.1.0-alpha.1`

## Verify the download
`SHA256SUMS` lists the checksums of the attached files. Each file also carries a GitHub build-provenance
attestation: `gh attestation verify <file> --repo Pranavk098/context-fabric`.

## Known limits
Use on a single-user machine. Windows needs Git for Windows for the hook scripts. Port 47831 is fixed.
Hooks in the desktop app and VS Code are untested.
