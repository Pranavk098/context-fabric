# Context Fabric v0.1.1-alpha.1

Second alpha of the Claude Code plugin. **Experimental. The token saving is not proven.**
Everything here was exercised on one developer's Windows machine; treat the numbers as observations, not
results.

## What it is
A Claude Code plugin that watches a session, measures where its tokens go, and can brief sub-agents and carry
working state across `/compact` and `/clear`. It runs a small daemon on `127.0.0.1:47831`; nothing leaves the
machine.

## What works
- Install and uninstall with the Claude Code plugin commands; `cfxd doctor`, `status` and `stop` manage the
  local helper.
- Offline, counts-only analysis of your own transcripts: `audit`, `diet`, `waste`, `routing`, `refetch`,
  `replay`, `fidelity`, `week`, `ledger`, `tour` and `agent-audit` (Codex/OpenCode logs).
- Brief (facts for sub-agents) and carry (a small block re-injected after compaction), both on by default.
- `diet --apply` / `--undo` reversibly disables fully-unused local plugins.
- Output is counts, sizes, hashes and model ids; `--share` output is designed to be pasted.

## What is experimental
- `/checkpoint`: saves the working state plus a goal note and the last test result, restores it once after
  `/clear`, and marks files that went missing or changed. The saving is unproven.
- `bound`, `coach` and the idle notice: off by default, effect unproven.
- `week`, `ledger` and `tour`: convenient summaries over the same measurements, not new evidence.
- The plugin A/B harness (`evals/plugin_ab`): a pre-registered protocol with session-length strata and a
  checkpoint arm. It has not produced a paired result yet.

## What is NOT proven
- That using this plugin reduces tokens or cost on real work. No paired test has finished.
- That brief or carry improves answer quality.
- That checkpoint restore is reliable enough to rely on as the only copy of your state — it is a convenience,
  not a backup.
- Any macOS behaviour: CI runs the tests there, but we have not hand-tested the plugin on a Mac.

## Known limits
- **Windows needs Git for Windows**, because the hooks run `sh launch.sh`. Check with `sh -c "echo ok"`; if it
  fails, install Git for Windows from <https://git-scm.com/download/win> and open a new terminal.
  `cfxd doctor` prints the same check and link.
- Hooks can drop events under load (for example when a turn ends while the daemon is busy). Checkpoints are
  then completed from the session transcript; a fact that never reached either may still be missing.
- Port 47831 is fixed in this alpha.
- Use it on a single-user machine; any process running as you can read the per-install token.
- Only the terminal CLI is hand-tested. Hook execution in the desktop app and VS Code is expected but not
  verified by us.

## Install
```bash
claude plugin marketplace add Pranavk098/context-fabric#v0.1.1-alpha.1
claude plugin install context-fabric@context-fabric
```
Then restart Claude Code. Full steps, requirements and troubleshooting:
[docs/INSTALL-ALPHA.md](../INSTALL-ALPHA.md).

Verify:
```bash
uvx --from git+https://github.com/Pranavk098/context-fabric cfxd doctor
```

## Uninstall
```bash
claude plugin uninstall context-fabric@context-fabric
uvx --from git+https://github.com/Pranavk098/context-fabric cfxd stop
```
Then delete `~/.cfx` (Windows: `Remove-Item -Recurse -Force $HOME\.cfx`) to remove stored notes, logs and the
token.

## Verify the download
`SHA256SUMS` lists the checksums of the attached files. Each file also carries a GitHub build-provenance
attestation: `gh attestation verify <file> --repo Pranavk098/context-fabric`.

## Send feedback
Copy [`docs/FEEDBACK-TEMPLATE.md`](../FEEDBACK-TEMPLATE.md) into an issue or an email and fill in what you
can; short answers are fine. Include the first line of `cfxd week --share` so we can match the version.

## Security
Hooks are authenticated with a per-install token and fail open; the daemon listens on loopback only and checks
the daemon's identity before sending a payload. Secret masking is best-effort and cannot be complete, and
restored context can carry prompt injection. Full model and reporting steps: [SECURITY.md](../../SECURITY.md).
