# Context Fabric v0.1.1-alpha.2

Third alpha of the Claude Code plugin. **Experimental. No saving is proven.**
Everything here was exercised on one developer's Windows machine and in CI; treat the numbers as
observations, not results.

A Claude Code plugin that watches a session, measures where its tokens go, and can brief sub-agents and carry
working state across `/compact` and `/clear`. It runs a small daemon on `127.0.0.1:47831`; nothing leaves the
machine.

## Version and commit
- Version: `0.1.1-alpha.2` (package `0.1.1a2`; tag `v0.1.1-alpha.2`).
- Commit: `<COMMIT>`.
- Every CLI header and every share payload reports this version (the `plugin_version` field), so tester data is
  sliceable by build.

## Ships
- Install and uninstall with the Claude Code plugin commands; `cfxd doctor`, `status` and `stop` manage the
  local helper. `cfxd doctor` prints six deep checks (daemon, token, hooks, state dir, Claude Code, launcher)
  first and its output is paste-safe: no paths, prompts or text.
- Offline, counts-only analysis of your own transcripts: `audit`, `diet`, `waste`, `routing`, `refetch`,
  `replay`, `fidelity`, `week`, `ledger`, `tour`, `checkup`, `handoff-stats` and `agent-audit`
  (Codex/OpenCode logs).
- Brief (facts for sub-agents) and carry (a small block re-injected after compaction), both on by default.
- `week --share` and `handoff-stats --share` emit the `cf-share/2` block: built field by field from an
  allowlist and validated on both the text and JSON renders.
- `week` and `handoff-stats` lead with limit-weighted new tokens (metric `limit-weighted/1`); raw counts sit
  behind `--verbose`. No plan-limit share is shown, because Anthropic publishes no token-denominated 5-hour
  or weekly limit for any tier (decision D-3), so no figure implies a percentage of your plan.
- `diet --apply` / `--undo` reversibly disable fully-unused local plugins; before/after is labelled
  `observed (this machine, this project, N sessions)`.

## Opt-in (off by default)
- Brief v1 excerpts, carry v2, the sub-agent carry-back, `coach` and the idle notice: off until you turn them
  on. Their effects are unproven.
- Turning `coach` on puts you in a measurement study.

  > **Coach study disclosure (coach is off by default):** You are in a measurement study if you turn coach on. Half of testers see coach prompts and half do not; which half you are in is fixed by a hash of your install. You can leave the study any time with `cfxd set coach off`.

## Does not ship
- Backward dedupe. Exact repeats measured 0.1% of new tokens and near-duplicates 0.0%, below the frozen 5%
  bar, so this release does not build it; it stays a framework-track experiment.
- Any plan-limit share or plan-tier percentage: none is published, and none is invented.
- Wired restart timing or a working-set tracker in the daemon: the tracker ships as a pure module that no
  feature uses yet.
- Any saving figure or saving claim for any feature.

## Known gaps
- **Windows needs Git for Windows**, because the hooks run `sh launch.sh`. Check with `sh -c "echo ok"`; if it
  fails, install Git for Windows from <https://git-scm.com/download/win> and open a new terminal.
  `cfxd doctor` prints the same check and link.
- **macOS is verified by CI install-smoke only**; we have not hand-tested the plugin on a Mac.
- **Hooks can drop events under load** (for example when a turn ends while the daemon is busy). Checkpoints
  are then completed from the session transcript; a fact that never reached either may still be missing.
- Port 47831 is fixed in this alpha.
- Use it on a single-user machine; any process running as you can read the per-install token.
- Only the terminal CLI is hand-tested. Hook execution in the desktop app and VS Code is expected but not
  verified by us.

## Install
```bash
claude plugin marketplace add Pranavk098/context-fabric#v0.1.1-alpha.2
claude plugin install context-fabric@context-fabric
```
Then restart Claude Code. Full steps, requirements and troubleshooting:
[docs/INSTALL-ALPHA.md](../INSTALL-ALPHA.md).

Verify:
```bash
uvx --from git+https://github.com/Pranavk098/context-fabric@v0.1.1-alpha.2 cfxd doctor
```

Uninstall:
```bash
claude plugin uninstall context-fabric@context-fabric
uvx --from git+https://github.com/Pranavk098/context-fabric@v0.1.1-alpha.2 cfxd stop
```
Then delete `~/.cfx` (Windows: `Remove-Item -Recurse -Force $HOME\.cfx`) to remove stored notes, logs and the
token.

## Share mode
`--share` output is `cf-share/2`: numbers and model families only. It carries no paths, prompts, commands,
tool output, repository names or session ids. Name digests exist only behind `--include-name-digests`, which
prints a warning and must never be pasted. The payload is built field by field from an allowlist: anything
not on it is dropped, not filtered out of a richer object.

## Feedback
Read [docs/testers/README.md](../testers/README.md) for the tester guides, then submit findings with the
[Tester report form](../../.github/ISSUE_TEMPLATE/tester-feedback.yml) (numbers only, never prompts, paths or
commands). The form asks two separate consent questions: one for the coach measurement study and one for
publishing aggregated counts. Short answers are fine; include the first line of `cfxd week --share` so we can
match the build.

## Security
Hooks are authenticated with a per-install token and fail open; the daemon listens on loopback only and checks
the daemon's identity before sending a payload. The daemon audits the state dir against declared content
classes at startup; secret masking is best-effort and cannot be complete, and restored context can carry
prompt injection. Full model and reporting steps: [SECURITY.md](../../SECURITY.md).

No saving is proven.
