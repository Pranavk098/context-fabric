## Method

- Join: the Gate 1 join, imported unchanged: parent `Agent` tool_use, then `toolUseResult.agentId`, then the child transcript.
- Parent cost: every priced assistant turn in the parent transcript, usage counted once per `message.id` (`cfxd/usage_dedupe.py`), at the repo's list prices.
- Child cost: every joined child's cost from Gate 1, which also excludes child messages that replay parent history and unpriced children.
- Total session cost = parent cost + joined child cost.
- Lower / upper: Gate 1's attribution of a child's cost to redundant calls (re-read of a file the parent knew, re-run of a parent Bash command), divided here by total session cost instead of child cost.
- Pooled shares are dollar-weighted across all sessions; per-session quartiles weight every session equally.
- Parent knowledge: distinct paths the parent Read/Edited/Wrote on lines before its first `Agent` call (Bash commands are matched separately and are not counted as files).

## Caveats

- This is one person's sessions on one machine. Parent and child costs are list prices, not a bill.
- Total session cost can be too low: children with no agentId link, a missing transcript or an unpriced model are excluded, so their spend is not in the denominator and the reported shares are if anything too high.
- The parent transcript is priced from its own model turns only. Work done outside the transcript (other tools, the user's own reading) is not in the denominator.
- Gate 1's parent knowledge is only what its Read/Edit/Write/Bash calls show; context from the user's prompt, compacted history or MCP tools is invisible, so re-discovery is undercounted and the lower/upper band may sit too low.
- The lower figure ignores that a redundant result stays in context; the upper charges the whole turn and its carried results and estimates result tokens from characters. Treat the truth as between them.
- A re-read is not always waste: a child may need the exact bytes in context to edit.
- Sessions are grouped by files the parent knew before its first spawn, so a session that spawned early and learned later is in the low group.
