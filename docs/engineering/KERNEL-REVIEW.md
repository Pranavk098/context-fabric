# KERNEL-REVIEW — Stage C Deterministic Context Compiler

- **Scope:** `kernel/router/{compiler,packer,dependency_closer,policy_engine,scorer,recall}.py`,
  `kernel/cartridge/{serializer,ast_extractor,pagerank_map}.py`, `protocol/{models,canonical,signing}.py`,
  `tests/test_{kernel,signing,protocol}.py`, cross-checked against `ADR-0001..0005` and `Arch-Spec.md`.
- **Method:** full read + targeted read-only execution against the repo venv (`.venv`, CPython 3.12).
  No code modified.
- **Severity:** S1 = correctness/security; S2 = robustness / violated stated invariant; S3 = minor.

## Findings

| ID | Sev | File:line | Description | Concrete fix |
|----|-----|-----------|-------------|--------------|
| **K-01** | **S1** | `kernel/router/policy_engine.py:23-45`, `kernel/router/compiler.py:92` | **Cross-tenant / trust-domain bypass.** `apply_policy` takes only `role` + `as_of`; it never compares `block.trust_domain` to `scope.tenant_id`, never checks `allowed_purposes` or `classification`. `compile_packet` passes no tenant/purpose. Verified: a block with `trust_domain="evil-corp"` is packed into a `t1` packet. Violates invariant 2 (trust-domain gate) and ADR-0004 §3 single-tenant isolation. | Pass `tenant_id` (and purpose) into `apply_policy`; deny unless `b.trust_domain == tenant_id` and `b.classification`/`allowed_purposes` permit. |
| **K-02** | **S1** | `kernel/router/compiler.py:123-124` | **Instruction duplicated into `observations`.** `packer.tier3` starts with the instruction, and `observations = tuple(b for b in packed.tier3 if b.block_kind is not shadow_probe)` therefore includes it. Verified: `observations kinds == ['instruction','fact']`. The instruction is rendered twice (`tier3.instruction` + `observations[0]`) while `total_tokens` counts it once → real rendered tokens exceed the declared budget. | Exclude instruction kind: `observations = tuple(b for b in packed.tier3 if b.block_kind not in (BlockKind.shadow_probe, BlockKind.instruction))`, or have `pack()` return `observations` separately. |
| **K-03** | **S1** | `kernel/router/compiler.py:93-97` | **Dependency/closure is a no-op for inclusion.** `close(allowed, by_id, ...)` passes the *same* allowed set as both `selected` and `all_blocks`, so `depends_on`, the missing side of `contradicts`, and `negative_knowledge` force-inclusion can never add a block that is not already selected. Verified: a `depends_on` target absent from the candidate list is **not** pulled in. Invariant 8 (negative knowledge must reach the agent) and the whole "Dependency Closer" stage are unrealized. | Pass the full block corpus as `all_blocks`/`by_id` and only the ranked candidate subset as `selected`; or run closure over the entire retrieved corpus before packing. |
| **K-04** | S2 | `kernel/router/policy_engine.py:38` | **Deny-by-default violated.** `if b.allowed_roles and role not in b.allowed_roles` treats an empty `allowed_roles` as "allow everyone". Verified: a block with no role grants is routable to an arbitrary role. Contradicts invariant 2 ("every block is denied by default"). | Require an explicit grant: deny when `role not in b.allowed_roles` (default `allowed_roles=()` ⇒ deny), matching `denied_roles` semantics. |
| **K-05** | S2 | `kernel/router/packer.py:125-129`, `protocol/models.py:248-255` | **Tier-0/reserve not enforced; oversized cartridge crashes compile.** `pack` caps t1/t2/t3 at their nominal budgets but adds `cartridge_tokens` unconditionally and never checks `budget.tier0` or `budget.reserve`. A cartridge with `token_count > tier0` pushes `total` past `hard_total_tokens`; the drop loop can only shrink Tier 3 to the instruction, then `ContextPacket` raises `ValueError`. Verified: `total_tokens (4710) exceeds hard_total_tokens (4000)`. ADR-0005 rule 2 (`total_tokens + reserve ≤ hard_total`) is not enforced. | Cap/validate `cartridge_tokens <= budget.tier0`; enforce `total <= hard_total_tokens - reserve`; route the dropped tier-3 blocks to Tier 2 instead of discarding. |
| **K-06** | S2 | `kernel/router/compiler.py:97` | **Watermark not enforced.** Blocks are packed regardless of `source_event_seq`; a block with `seq > watermark_event_seq` is included. ADR-0002 requires Tier 1 to be a pure function of `(tenant, project, workflow, watermark)` for KV-prefix sharing to be sound. | Filter `blocks` to `b.source_event_seq <= watermark_event_seq` before policy/closure (or reject out-of-watermark inputs). |
| **K-07** | S2 | `protocol/models.py:89-90` (see also PROTOCOL-REVIEW P-07) | **Wall-clock defaults break determinism.** `observed_at`/`valid_from` default to `_now()` and are embedded in every packed block, so they enter `content_hash`. Two compiles from independently reconstructed, otherwise-identical blocks produce different hashes unless every caller pins timestamps. | Make timestamps required (derive from the source event) or exclude volatile temporal fields from the hashed logical packet; add a test that builds blocks twice and asserts equal hashes. |
| **K-08** | S2 | `kernel/router/compiler.py:128-130` | **`packet_id` collision.** `packet_id` hashes `(workflow, task, agent, watermark)` but not `objective`/`stage`, while packet content depends on both. Two different compiles (different objective, same watermark) share one `packet_id` → storage/idempotency collision. | Include all content-affecting inputs (objective, stage, role) in the `packet_id` preimage, or make `packet_id = content_hash`. |
| **K-09** | S2 | `kernel/router/dependency_closer.py:47-69` | **`supersedes` can be undone.** Order is depends_on → supersedes → contradicts → negative_knowledge. A block deleted by `supersedes` can be re-added by the later `contradicts` or negative-knowledge loops, silently resurrecting superseded content. | Record superseded ids and exclude them at the end, or apply `supersedes` after the other closures with a fixed-point re-run. |
| **K-10** | S2 | `kernel/router/policy_engine.py` (whole) | **Purpose/classification gates absent.** `allowed_purposes`, `classification`, and `verified` are never consulted despite the engine docstring claiming purpose/trust gates. | Add purpose and classification checks to `apply_policy`; thread the recipient purpose through `compile_packet`. |
| **K-11** | S2 | `kernel/router/packer.py:97-104`, `kernel/router/scorer.py:32-37` | **MMR and U-curve are not implemented; cache discount is dead.** The pipeline docstring and ADR-0003/Arch-Spec claim "MMR/Greedy packing" and a "U-Curve Anchor", but packing is greedy-by-utility plus a tail-drop loop, and blocks are never re-ordered into a U-shape. `utility(..., cached=...)` is never passed `True` anywhere, so `EffCost` cache discount never applies. | Either implement MMR/U-curve ordering and pass `cached` from Tier 0/1 membership, or correct the docstrings/ADR claims to describe the actual greedy packer. |
| **K-12** | S2 | `kernel/cartridge/serializer.py:52-53` | **Hologram truncation discards all lower-ranked files.** `if count_tokens(...) > budget_tokens: break` stops at the first file that does not fit, so one oversized high-rank file excludes every lower-ranked file that would fit. | Use `continue` (skip the oversized file) instead of `break`. |
| **K-13** | S2 | `kernel/router/packer.py:127-129` | **Hard-overflow Tier-3 blocks are silently lost.** The reduction loop pops Tier-3 blocks but never converts them to Tier-2 `SwapHandle`s, violating invariant 6 (reversible eviction, never lossy amnesia). | Append dropped blocks to `overflow` and re-run the Tier-2 handle loop after reduction. |
| **K-14** | S3 | `kernel/router/compiler.py:157`, `kernel/router/compiler.py:160-164` | Signature stored as bare hex, not `"ed25519:…"` as ADR-0005 shows; `key_id` is placed in `hashes` though ADR-0003 §5 says the route trace records it. | Prefix the signature per schema; move/duplicate `key_id` into `route_trace_ref` (or amend the ADR). |
| **K-15** | S3 | `kernel/router/policy_engine.py:41` | Freshness gate only checks `valid_to <= as_of`; a not-yet-valid block (`valid_from > as_of`) is admitted, and the Arch-Spec §4 "freshness ≥ task_floor" concept is absent. | Add `valid_from > as_of ⇒ deny` and an explicit freshness floor parameter. |
| **K-16** | S3 | `kernel/router/packer.py:27-35,90-94` | `_LEDGER_KINDS`/`_TIER3_KINDS` omit `cartridge_hologram` (and `instruction`), so such blocks are neither packed nor overflowed — silently dropped. | Add a default bucket or assert every incoming kind is handled. |
| **K-17** | S3 | `kernel/cartridge/ast_extractor.py:34,62-64` | Every `ast.Name` (including locals and params) counts as a reference, creating false PageRank edges when a local shares a name with an exported symbol; `_func_sig` ignores `*args`, `**kwargs`, keyword-only args, defaults, and decorators. | Restrict references to module/attribute/import loads; include the full argument spec in signatures. |
| **K-18** | S3 | `kernel/router/scorer.py:26-37`, `kernel/router/recall.py:16-28` | `U(i)` implements 3 of the 10 terms in Arch-Spec §4 (no role/stage/fresh/auth/dep/conflict/prune/risk), and recall is lexical overlap rather than the specified BM25 + symbol-graph + explicit refs. | Reconcile the scoring/recall implementation with the spec, or scope the spec to what Stage C ships. |
| **K-19** | S3 | `tests/test_kernel.py:116-134,154-162`, `tests/test_protocol.py:27-30` | **Tests that pass for the wrong reason.** `test_dependency_and_negative_knowledge_closure` passes only because every allowed block is already selected (K-03) — it asserts nothing about closure; `test_adaptive_cartridge_absent_for_small_projects` only checks the `cartridge=None` default (no size logic exists); `test_signature_excluded_from_hash` never sets a signature, so the exclusion is vacuous. | Pass a genuine candidate subset and assert the closer *adds* a non-selected block; set a real signature before hashing; rename/repurpose the adaptive test. |
| **K-20** | S3 | `kernel/router/dependency_closer.py:59,67,73-75` | Negative-knowledge matching compares case-sensitive block symbols against lowercased objective tokens (`nk_syms & obj_tokens`), so it misses matches; `contradicts` alerts are emitted once per relation with no de-duplication. | Normalize both sides to the same case; de-duplicate alerts by unordered pair. |
| **K-21** | S3 | `kernel/router/compiler.py:60,168` | Constant `block_id="blk_instruction"` can collide with a real block id, and the instruction is omitted from `trace["included"]` while `observations` (K-02) duplicates it. | Use a reserved id namespace and include/exclude the instruction consistently in the trace. |

## Verified sound

- **Policy-before-ranking ordering** (invariant 2): `apply_policy` runs before scoring and closure, and
  `close()` only reads from the allowed `by_id`, so a policy-denied block cannot be re-introduced by
  dependency closure.
- **JCS canonicalization** (`protocol/canonical.py`): ECMAScript number formatting (P-01) and
  enum-before-`int` dispatch (P-02) are fixed; UTF-16 key ordering, string escaping, and `sha256:`-free
  `content_hash` are correct and pass the Appendix-B vectors.
- **`packet_content_hash`** empties the entire `hashes` block → idempotent and signature-independent;
  confirmed with a real signed packet (`packet_content_hash(p) == p.hashes.content_hash`).
- **`TokenBudget`**: `from_base` proportions (15/25/5/45/10) sum exactly to `hard_total_tokens` and
  reject bases not divisible by 20; `_within_budget` and `Tier1Ledger._ordered_by_event_seq` validators
  are present.
- **PageRank** (`pagerank_map.py`): sorted node/edge iteration, fixed `alpha`/`iters`/`tol`, and dangling
  redistribution make it deterministic and reproducible; the serializer tie-breaks by path, so
  cartridge output is order-independent.
- **Signing** (`protocol/signing.py`): Ed25519 sign/verify round-trips, tamper detection works, and
  `key_id` is stable and derived from the public key; signing is off the hashed critical path.
